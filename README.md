## Featured project

### Damas Cognitivas (Integrator Project V)

An interactive, modern checkers game designed for cognitive stimulation. Players face an adaptive AI across a 10-stage journey of increasing difficulty.

**[Play it live](https://damas-cognitivas.vercel.app)** · **[Source code](https://github.com/EduFGomes/PI_V_ES_TIME17)**

- AI built with **Minimax and Alpha-Beta pruning**, with parameters that scale as the player progresses (search depth, controlled error rate, heuristic aggressiveness)
- Three difficulty profiles, a hint system that highlights valid moves, and customizable pieces and backgrounds
- Drag-and-drop gameplay, smooth animations and an interactive tutorial
- Decoupled architecture: **React 19** front-end and **Flask** REST API, deployed on Vercel
